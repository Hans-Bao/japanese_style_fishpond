# japanese_style_fishpond · 鯉の池

一个纯前端的日式锦鲤池网页。Canvas 2D 程序化绘制，**无任何依赖、无需构建**：锦鲤在池中游荡、跟随指针、浮上水面吃食，配以实时水波涟漪、焦散光、四季庭园与飘落的樱花 / 枫叶 / 雪 / 小雨。

## 快速开始

直接双击 `index.html` 即可在浏览器中打开。也可以用任意静态服务器：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

> 字体使用 Google Fonts（Shippori Mincho / Noto Serif SC），离线时会自动回退到系统宋体。

## 功能

### 锦鲤
- **游荡**：自由巡游、同伴间互相避让、靠近池边自动转弯，深浅不一（越深越朦胧，投影越近）
- **跟随**：指针在水面上移动，附近的鲤鱼会游过来围着打转
- **投喂**：点击水面撒鱼食，鲤鱼冲过去、**浮出水面张嘴吞食**，激起金色涟漪
- **13 个品种**：红白、大正三色、昭和三色、丹顶、黄金、白金、浅黄、茶鲤、黄鲤、红鲤、白写、绯写、九纹龙；约 25% 为长鳍“蝴蝶鲤”
- **矢量体积光影**：身体边缘渐暗与背脊高光、鳞片纹理、半透明渐变的鳍与柔软飘动的尾鳍链、眼睛高光与鱼须
- **数量**按屏幕分辨率自动适配（手机约 5 尾，桌面约 13 尾），也可手动指定

### 水面
- **水波高度场模拟**：涟漪会扩散、叠加、在池边反射，并带动漂浮物与鱼影晃动
- **焦散光**：域扭曲 Worley 噪声生成的青白色光网，两层反向流动
- 金色涟漪圈、水面金屑与星芒闪光、岸边树木的水中倒影

### 环境
- **6 种庭园**：苔庭、枯山水、木栈道（八桥式 + 菖蒲）、朱桥庭园、寺院缘侧、竹林
- **4 个季节**：樱花 / 新绿 / 红枫 / 积雪，影响树木、地面、灌木、石头积雪及水面漂浮物（夏季荷叶与莲花）
- **3 个时辰**：白天、黄昏（暖色调）、夜晚（石灯笼点亮、月影、夏夜萤火虫）
- **飘落**：樱花、枫叶、雪、小雨可任意组合，默认随季节随机；花瓣落叶落水后漂浮，雨滴激起涟漪
- **小生物**：蜻蜓在荷叶间飞停，鱼浮上来会把它惊飞

## 设置

点击右上角按钮打开设置面板，所有选项实时生效，并保存在本地（localStorage）。

快捷键：`R` 重新随机 · `H` 隐藏界面 · `Esc` 关闭面板

### URL 参数

所有配置都可以通过 URL 指定；面板中的修改会同步到地址栏，“复制链接”会附带当前随机种子，便于分享同一个庭园。

| 参数 | 说明 | 示例 |
|---|---|---|
| `fish` | 鲤鱼数量，0 或省略 = 按屏幕自动 | `fish=12` |
| `species` | 品种，逗号分隔；省略 = 全部随机 | `species=kohaku,showa,ogon` |
| `env` | 庭园：`moss` / `karesansui` / `boardwalk` / `bridge` / `temple` / `bamboo` | `env=bridge` |
| `season` | `spring` / `summer` / `autumn` / `winter` | `season=autumn` |
| `time` | `day` / `dusk` / `night` | `time=night` |
| `weather` | `auto`（随季节）/ `none` / `sakura,maple,snow,rain` 任意组合 | `weather=sakura,rain` |
| `intensity` | 飘落强度 0.2 – 3 | `intensity=2` |
| `follow` | `0` = 关闭鲤鱼跟随指针 | `follow=0` |
| `ripple` | `0` = 关闭指针划过水面的涟漪 | `ripple=0` |
| `seed` | 固定随机种子，得到可复现的庭园 | `seed=42` |

未指定的项均为随机。示例：

- 雪夜朱桥：`index.html?env=bridge&season=winter&time=night`
- 夏日荷塘，只要红白与昭和：`index.html?env=moss&season=summer&species=kohaku,showa`

品种代码：`kohaku` 红白 · `sanke` 大正三色 · `showa` 昭和三色 · `tancho` 丹顶 · `ogon` 黄金 · `platinum` 白金 · `asagi` 浅黄 · `chagoi` 茶鲤 · `kigoi` 黄鲤 · `benigoi` 红鲤 · `shiroutsuri` 白写 · `hiutsuri` 绯写 · `kumonryu` 九纹龙

## 项目结构

```
index.html          页面与设置面板
css/style.css       界面样式
js/utils.js         数学、可复现随机数、颜色工具
js/config.js        品种/环境/季节定义，URL 参数与本地存储，随机项落地
js/pond.js          池塘形状、水波高度场模拟、涟漪圈、焦散纹理
js/koi.js           锦鲤外观生成、行为（游荡/跟随/觅食）、绘制
js/weather.js       鱼食、漂浮物（荷叶/莲花/花瓣/落叶）、天气粒子、蜻蜓、萤火虫、金屑
js/environment.js   程序化绘制庭园：地面、池底、池岸、树木、灯笼、桥、栈道、倒影
js/main.js          世界状态、主循环、分层渲染与交互
js/ui.js            设置面板
```

**渲染分层**（每帧）：缓存的地面与池底 → 焦散 → 鱼影 → 水下的鱼 → 水体与倒影 → 涟漪光影 → 鱼食 / 漂浮物 / 浮出水面的鱼 / 金屑 → 缓存的池岸与景物 → 蜻蜓与天气粒子 → 时辰氛围与灯光。

环境层只在切换庭园、季节或窗口尺寸变化时重绘一次，每帧只做贴图。
